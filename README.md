# etalii.adp.ide.thinkrail

[![Build](https://github.com/etalii-adp/etalii.adp.ide.thinkrail/actions/workflows/build.yml/badge.svg?branch=develop)](https://github.com/etalii-adp/etalii.adp.ide.thinkrail/actions/workflows/build.yml?query=branch%3Adevelop)

The ADP tools for JetBrains ThinkRail: an IDE host that brings ADP tools to ThinkRail, as the IntelliJ host brings them to the IntelliJ Platform IDEs. There is no code yet; what this repository builds is specified in [etalii.adp](https://github.com/etalii-adp/etalii.adp) before any is written.

ADP, A Different Perspective, is a range of task-focused tools: diagrams, designers and editors (see the [ADP terminology](https://github.com/etalii-adp/etalii.adp/blob/develop/docs/terminology.md)). The site is at <https://etalii.net/adp/>.
